A program that draws Friday 27 November 2026 as a one-page newspaper
front page — a single 1024×1024 image, generated with the Python
standard library only.

## The day's news in the image

- **Black Friday** is the lead story: shoppers are out today, with
  $12.9 billion of US online spending expected (Adobe's forecast, not
  a result — the day has only just begun), and stores open from 6 a.m.
- **Tokyo prices up 2.9%** — core inflation in Japan's capital stayed
  above the Bank of Japan's 2% target.
- **Test decider begins** — India bowl first in Christchurch, and
  Gurnoor Brar makes his Test debut.
- **Forest v Chelsea tonight** — the Premier League weekend opens at
  the City Ground, 8 p.m.

Every story in the image happened or was first reported on Friday
27 November 2026. Nothing from Thursday 26 November appears here.

## Run it

```sh
python3 main.py
```

This writes `out/entry.png` (1024×1024, under 1 MiB). Set
`MAKEFUN_OUTPUT_DIR` to choose a different output folder. The image
is deterministic: running it twice produces byte-identical files.
